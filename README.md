# 우리 가족 여행 아카이브

날짜와 지역별로 여행계획서를 축적하는 모바일 우선 정적 PWA입니다. `2026.07.27–30 통영·거제 가족여행`과 `2026.08.14–16 여수 가족여행`을 제공합니다.

## 핵심 UX

- 홈 전체 화면: 여행지·맛집·카페 검색, 지역→도시 필터, 최신 여행 우선 띠배너 목록
- 상세 전체 화면: 홈 UI와 분리된 DAY별 여행계획서
- 장소 검색: 일치하는 일정 영역으로 바로 이동
- 자동 위치 복원: 지도·외부 브라우저·백그라운드 작업 후 돌아오면 마지막으로 보던 상세 위치 유지
- 홈 상태 복원: 뒤로가기 시 검색어·필터·목록 스크롤 유지
- PWA 캐시: 한 번 연 페이지는 네트워크가 불안정해도 기본 열람 가능

## Vercel 배포

Framework Preset은 `Other`, Build Command와 Output Directory는 비워둡니다. 저장소 루트를 그대로 배포하면 됩니다.

> `robots.txt`와 `X-Robots-Tag`는 검색엔진 노출을 차단하지만 URL 접근 자체를 인증으로 제한하지는 않습니다.

## 여행 추가

1. `data/trips.json`에 여행 메타데이터와 검색 키워드를 추가합니다.
2. `trips/{여행-id}/index.html`에 상세 계획서를 추가합니다.
3. 검색어가 특정 일정으로 바로 이동해야 하면 `matches`에 검색어와 앵커 ID를 연결합니다.

## 디자인 원칙

승인된 디자인 시안은 `docs/design/`에 보존했습니다. 딥 포레스트 그린, 웜 아이보리, 오션 틸, 절제된 테라코타를 사용하며 홈과 상세를 서로 다른 전체 화면으로 유지합니다.
