# 안양중앙시장 가족 공통 선택 목록

## 사용 방식
- 운영 페이지: `/trips/anyang-market-2026-11/`.
- 가족 링크: 동일 페이지 뒤에 `#family=<비밀키>`를 붙인 **별도 초대 링크**. 실제 키는 GitHub나 본 문서에 넣지 않습니다.
- 최초 접속은 해시에서 비밀키를 읽어 브라우저에 저장하고 주소창의 해시를 지웁니다. 재접속 시 저장된 키로 접속하고, '가족 링크 공유' 버튼으로 다시 초대할 수 있습니다.
- **초대 링크 없이 일반 링크만 접속**하면 기존 로컬 선택 방식으로 남으며, 페이지에 기기 전용 상태임을 명시합니다. 가족 공통 목록 사용을 위해서는 초대 링크가 필요합니다.
- 초대 링크를 가진 사람은 읽기 및 수정이 모두 가능합니다. 계정별 사용자 구분·편집 권한 회수 기능은 현재 없습니다. 링크가 유출되면 서버의 `FAMILY_SHARE_TOKEN`을 변경하고 새 초대 링크를 배포해야 합니다.

## 저장 및 보안
- Vercel Private Blob 저장소(서울 `icn1`)의 `family-picks/anyang-market-2026-11.json` 한 문서에 선택 ID/버전/작업 ID만 저장합니다. 이름, 위치, 연락처 등 개인정보를 저장하지 않습니다.
- 서버는 환경변수 `FAMILY_SHARE_TOKEN`과 클라이언트 Bearer 토큰을 timing-safe SHA-256 비교로 검증합니다. 비밀키를 소스 코드/응답으로 공개하지 않습니다.
- API는 `/api/family-picks`; 같은 출처 HTTPS 요청의 Authorization 헤더로 인증하며 브라우저 및 PWA 캐시를 우회합니다.
- PUT은 Blob의 ETag `ifMatch`로 조건부 저장하고 충돌 시 재조회 후 재시도합니다. 새 문서 생성 충돌도 재시도합니다. POST 작업은 UUID로 중복 요청을 제거합니다.
- 두 기기의 별개 장소 수정은 서버 순서대로 누적됩니다. **동일 장소를 동시에 수정하면 서버에 마지막으로 성공한 요청이 적용됩니다.**
- 열려 있는 화면은 10초 주기로 새 상태를 확인하고, 탭 복귀/온라인 복구 시에도 갱신합니다. 인터넷 장애 시 미전송 작업은 현재 브라우저에 보관해 재연결 후 재전송합니다.

## 기존 선택 이전
- 구 로컬 스토리지 키 `travelArchive:anyang-market:picked:v1`를 자동 삭제하거나 덮어쓰지 않습니다.
- 가족 링크 최초 연결 후 서버 목록에 없는 로컬 선택이 있으면 '기존 선택 합치기'를 표시하며, 사용자가 누를 때 서버 목록 뒤에 추가됩니다. 기존 서버 선택은 보존합니다.
- 건너뛰기를 누르면 로컬 데이터는 남지만 공동 목록에 업로드하지 않습니다. 이 브라우저에서 해당 프롬프트는 다시 나타나지 않습니다.
- 다른 브라우저에서 이전에 저장한 개인 선택은 그 브라우저에서 가족 링크를 열고 가져와야 합니다.

## 검증 기준
1. 인증 없이 GET/POST 시 401, 비밀키는 HTML/JS/응답에 없음
2. 신규 공유 목록은 빈 상태, 서로 다른 두 브라우저의 선택/해제/정렬이 동일
3. 동시에 서로 다른 두 장소 선택 시 두 항목 모두 보존
4. 작업 중복 재시도 시 중복 반영 없음
5. 미전송 작업 저장 후 새로고침해도 복구하여 제출
6. 기존 선택을 사용자 승인으로 병합, 기존 클라우드 선택 보존
7. 선택 UI, 카테고리, 16곳 데이터, 네이버지도 링크 유지

## 운영 주의
- 인증된 실기기 테스트 및 유출 시 키 회전은 별도 확인이 필요합니다.
- 데이터 손실을 막으려면 저장소를 삭제하거나 연결 해제하지 마십시오.
