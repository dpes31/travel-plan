# 안양중앙시장 가족 공통 선택 목록 · 기존 URL 자동 동기화

## 서비스 원칙
- **한 가지 일반 링크**: `https://travel-plan-ashen.vercel.app/`에서 안양중앙시장 페이지로 이동하거나, `/trips/anyang-market-2026-11/`에 직접 접속합니다.
- 로그인·비밀번호·초대 링크·개별 가족 토큰 없이 모든 브라우저와 디바이스가 **같은 16개 장소의 선택 목록**을 읽고 수정합니다.
- 누구든 주소를 알면 목록을 읽고 수정할 수 있습니다. 이는 사용자가 명시적으로 선택한 공개 공동 편집 모드이며, **접근 제어 또는 개인별 작업 식별은 제공하지 않습니다**. noindex는 보안 통제가 아닙니다.
- 서버 환경변수 `BLOB_READ_WRITE_TOKEN`은 비공개 Blob 접근에만 사용하며 브라우저에 공개하지 않습니다.

## 서버·동기화
- `GET /api/family-picks`: 초기 Blob 파일이 없어도 정상 빈 목록(200)을 반환합니다. 캐싱 금지.
- `POST /api/family-picks`: 등록된 16개 장소의 select/deselect 또는 명시적 legacy import만 승인합니다.
- Blob ETag `ifMatch` 조건부 쓰기, 충돌 재시도, operationId 중복 제거. 서로 다른 장소의 동시 변경은 직렬화해 보존합니다. 같은 장소의 충돌은 마지막으로 서버에 반영된 변경이 적용됩니다.
- 서버 쓰기가 확정되기 전에는 브라우저에 임시 작업 큐를 유지하고 연결 복귀 시 재전송합니다. 이미 열려 있는 다른 브라우저는 약 10초마다 갱신합니다.
- 서비스 워커는 `/api/` 요청을 캐시하지 않습니다.

## 기존 기기 선택 이전
- 브라우저 localStorage의 `travelArchive:anyang-market:picked:v1`은 읽기만 하고 지우지 않습니다.
- 기존 개인 선택이 서버 목록에 없는 경우 앱이 **‘기존 선택 합치기’** 또는 ‘건너뛰기’를 제안합니다. 아무 동의 없이 서버 공통 목록을 덮어쓰지 않습니다.
- 로컬 선택은 각각의 기존 브라우저에 있으므로, 필요하면 그 브라우저에서도 한 번씩 이전하세요.

## 검증
1. 최초 GET(문서 부재)은 200/빈 목록
2. POST 저장 후 다른 독립 접속에서 같은 목록 조회
3. POST 다른 장소 동시 수정 충돌 후 양쪽 선택 보존
4. 미전송 작업 재로드 복원 및 기존 선택 병합
5. 기존 디자인/문구/카테고리/장소 16곳/Naver 앱 링크 보존
6. 오류 발생 시 저장 완료로 잘못 표시하지 않음

## 운영 유의
- 공개 수정 방식이므로 외부인이 동일 링크를 알면 장소를 선택·해제할 수 있습니다. 요청 크기와 유효 장소 제한은 제공하지만 IP 단위 속도 제한 및 신원별 회수 기능은 구현하지 않았습니다.
- Vercel Blob은 오브젝트 CDN 캐시가 있어 빠른 연속 수정 후 오래된 읽기가 올 수 있으므로 실제 서버에서 연속 수정/재조회 검증을 반드시 수행해야 합니다.
